## What was learned and demonstrated

The native experiment uses FreeCAD for geometry, constraints, history and persistence behind a Rust interface. The latest work improved active geometry fields and corrected selection-chip synchronization and Full revolve expression handling. The completed 8 November checkpoint records 416 passing host tests, six separate catalog checks, and a production-host/native-worker control covering preview, Cancel, Apply, Undo/Redo, expression restoration and save/reopen. Those are historical results, not tests rerun today. See [checkpoint scope](2026-11-08.md).

The SolidCraft trial demonstrated a reversible Onshape controls preset, navigation, additive viewport selection, shortcut defaults and hidden grids. Its completed thread records four focused controls checks and an opened sample. Initial startup stack overflow and safe-mode software rendering were diagnosed; the final recorded run used Arc B580 through DX12 with Onshape controls enabled. This was an unoptimized development modeling build without the optional CPU renderer. Old failure logs remain in its private profile.

The central requirement is Onshape-style multi-part modeling and shared history, not only matching controls. Neither experiment established complete parity. The native project's historical whole-tutorial count remains 2; live GUI qualification of R500, raw BRep equality, physical acceptance and final common-build qualification remain open. SolidCraft's advanced tutorials and deeper Part Studio semantics remain unqualified. The numeric circle-helix candidate remains separate and unintegrated; its [handoff](2026-11-06/cad-circle-helix-sol-20261106-r490/HANDOFF.md) records the unresolved associative endpoint requirement. These gaps are parked, not an active backlog for this closeout.

## Reopen only on request

For a native CAD trial, first preserve any currently open document through the user's normal workflow. From the repository root, launch the retained R494 executable with `--runtime .tools/cad-windows-user-try-root-20261106-r494/runtime.json`. Its old `launch_ready.py` is historical: it creates logs exclusively and is not a repeatable launcher. Keep any new trial's documents and profile separate. R500 is the later development source/build to qualify before replacing R494; consult `.tools/cad-management-handoff-20261104-r1/CURRENT-R500.md` and its retained controls rather than rebuilding or installing automatically.

For SolidCraft, run `powershell -NoProfile -File .\Open-SolidCraft.ps1` from the repository root; add `-Sample` only when wanted. Keep the separate settings directory and explicit GPU selection. A newly launched session would still need its actual adapter and controls checked. Do not clear safe-mode or crash state blindly or overwrite a running user's profile.

For source recovery, use a **new empty scratch checkout** at the exact base above. Extract the corresponding archive there, preserving paths; never extract over the current work. The patches are an alternative for tracked changes, not an additional step after extracting those same files. The SolidCraft locale is included only in its ZIP. Restore parent untracked files separately from `unpublished-parent.zip`. Read the manifests before deciding which files to adopt. Do not run reset, clean or automatic restore against either existing tree.

Both inspected CAD schedules, **Hourly CAD bottleneck review** and **CAD reset-time continuation checkpoint**, are disabled with no next run. They were left unchanged. Do not re-enable them merely to reopen a trial.
